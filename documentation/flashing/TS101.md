# Flashing TS101

1. Unplug the TS101.
2. Hold the `A` button while connecting its USB-C cable to the computer.
3. Wait for the TS101 virtual drive to appear.
4. Copy the matching `TS101_<LANGUAGE>.hex` file to that drive.
5. Wait until the copied file is renamed to `.RDY`, then unplug and power the iron normally.

If the bootloader renames the file to `.ERR`, copy the `.hex` file again without deleting
the `.ERR` file first. This stock bootloader can occasionally require a second attempt.
